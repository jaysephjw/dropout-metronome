# Dropout Metronome

A browser metronome with a percent chance to drop random beats, for practicing steady internal time.

## Run

Open `index.html` in a browser. No build step or dependencies.

## Features

- 30–260 BPM, tap tempo, tempo markings
- 1–12 beats per bar, subdivisions (quarter, eighths, triplets, 16ths)
- Per-beat accent / normal / mute
- Drop chance 0–90%, single beats or whole bars
- Clean lead-in bars, option to always keep beat 1, option to hide drops on screen
- Last-32-beats history and session stats

## Keyboard

- Space: start / stop
- ← / →: ±1 BPM
- ↑ / ↓: ±5 BPM
- T: tap tempo
